# Vue 2 migration fixture

Four small Vue 2 Options API single-file components for testing VueToReact.ai's repository migration workflow. They cover local state, methods, lifecycle, conditions, loops, bindings, events, and scoped styles.

These components are independent fixtures, not a deployable app. Run the repository URL through VueToReact.ai's Repository tab; generated React files should be proposed in a draft pull request while the original `.vue` files stay unchanged.
